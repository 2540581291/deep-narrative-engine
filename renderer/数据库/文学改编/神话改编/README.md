# 神话改编 · 经典库数据

本文件是「文学改编 → 神话改编」的经典库数据源，位于 `renderer/数据库/文学改编/神话改编/`，工厂只读加载（`LocalFS.dbRead('文学改编/神话改编/神话.csv')`）。

## 数据来源与说明
- 本标准「确定无疑」的神话条目（女娲补天 / 盘古开天 / 嫦娥奔月 / 后羿射日 / 夸父追日 / 精卫填海 / 哪吒闹海 / 八仙过海 / 十二生肖 / 年兽 / 龙抬头 / 金乌玉兔…），**共 14 篇**，由「童话改编」库迁入。
- 来源标记「故事365·神话」，正文简体中文，可继续扩充（山海经/希腊神话/北欧神话等）。
