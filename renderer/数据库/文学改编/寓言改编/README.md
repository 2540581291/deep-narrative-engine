# 寓言改编 · 经典库数据

本文件是「文学改编 → 寓言改编」的经典库数据源，位于 `renderer/数据库/文学改编/寓言改编/`，工厂只读加载（`LocalFS.dbRead('文学改编/寓言改编/寓言.csv')`）。

## 数据来源与说明
- **伊索寓言**（周作人译，上海古籍/商务版电子书）——**357 篇**，作者「伊索」，来源「伊索寓言·周作人译」。正文含「这故事说明…」寓意段（已剥离版式符号 `◎`）。
- **拉封丹寓言**（李玉民译，世界三大寓言之一）——**154 篇**，作者「拉封丹」，来源「拉封丹寓言·李玉民译」。正文为诗体，含起承转合与点题句。
- **原「故事365·寓言」成语寓言**（守株待兔 / 掩耳盗铃 / 井底之蛙 / 狐假虎威 / 刻舟求剑 / 南辕北辙 / 鹬蚌相争 / 寒号鸟 / 揠苗助长 / 买椟还珠 / 郑人买履 / 塞翁失马 / 乌鸦喝水 / 农夫与魔鬼 / 金斧头…）——共 **21 篇**，作者留空。其中与拉封丹同名的「狼和小羊」已按「工作区文本为准」用拉封丹版覆盖。

合计 **532 篇**。

## 清洗与去重规则
- 剔除卷末非寓言条目「译后记·关于伊索寓言」「附录·伊索小传」。
- 成语寓言内剔除冗余：`---精简版/故事版---` 标记、`-----------` 分隔线、`欢迎分享/分享/继续阅读`、`｜…｜` 关联链接、重复段落（截断复述）、自带的文言原文块（《吕氏春秋》/《庄子》引文等）、词典注（近义词/反义词/造句/释义补注）。
- 重复篇目合并：`鹬蚌相争` 原分「渔翁得利」「渔人得利」两条 → 合并为一条；`吃不到葡萄就说葡萄酸…[狐狸和葡萄]` 与伊索「狐狸与葡萄」、拉封丹「狐狸和葡萄」重复 → 删除。
- 标题清理：去掉画蛇添足后缀（如「对牛弹琴（在古代，真的有人对牛弹过琴吗）」→「对牛弹琴」、「郑人买履（lǚ）」→「郑人买履」、「揠苗助长（拔苗助长）」→「揠苗助长」）。
- 同作者集合内按标题去重（保留首个与正文对应者）。
- 伊索与拉封丹为不同作者同名版本（如「狼与狗」「猴子与海豚」「狼和小羊」），各留一篇，均收录。
- 与原有「故事365·寓言」同名条目，以本工作区电子书文本为准则（覆盖）。
