# 名著改编 · 经典库数据

本文件是「文学改编 → 名著改编」的经典库数据源，位于 `renderer/数据库/文学改编/名著改编/`，工厂只读加载（`LocalFS.dbRead('文学改编/名著改编/名著.csv')`）。

## 数据来源与说明
- **共 34 篇中外古典/公版名著**（四大名著及中外经典，含原文摘录/名句），来源标记「中国古典名著 / 世界名著」，作者已填。
- 著名筛选可命中大部分（红楼梦/三国演义/西游记/水浒传/傲慢与偏见/简爱/战争与和平/双城记…）。

题目,朝代,作者,内容,来源,词牌

## 备注
- 可直接用于「去改编」；经典库支持 题材/主角/标签/篇幅/著名(著名·普通·安徒生·格林)/搜索 筛选。
- 后续如需更完整，可再补全文（如四大名著pdf/epub、或指定版本）或以更长摘录替换。
